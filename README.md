# 家計簿アプリ

## 概要

収入・支出を登録し、月ごとの収支を確認できるwebアプリ。

## 主な機能

- 収入・支出の入力
- 月ごとの収支合計
- データ保存
- 日、週、月ごとの履歴をカレンダーで見られるようにする
- 入力前に項目分け（ボタン式）
- どの項目が多いかのグラフ
- 固定費設定
- 予算メーター

## サブ機能
- 入力時の電卓機能
- 月ごとの収入、支出のうち片方だけ表示できる
- AIが収支を見て今後の方針などを考えてくれる、占い
- 通知、ウィジェット

## 使用技術

- html
- css
- javascript

## 開発ルール

1. mainから作業用branchを作る
2. 作業branchで実装する
3. githubへpushする
4. pull requestを作成する
5. 他メンバーが確認してmainへmergeする
